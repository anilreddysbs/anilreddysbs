PROJECT 01 · LLM INFRASTRUCTURE↗

LLM Gateway

An OpenAI-compatible API gateway that routes requests across Gemini and OpenAI-compatible providers through configurable model aliases, including Server-Sent Events streaming.

  • Atomic Redis Lua sliding-window rate limiting, exact-match response caching and lock-based stampede protection.
  • Monthly per-key budgets, exponential backoff with jitter, a Redis-backed circuit breaker and provider fallback before the first streamed chunk.
  • Decimal-based token/cost tracking, async batched PostgreSQL usage logs, admin analytics and Prometheus metrics.
  • Custom load tests: cache hits below 5 ms p50 and 100% success during a simulated primary-provider outage.
PYTHON · FASTAPI · REDIS · POSTGRESQL · DOCKER · PROMETHEUS
PROJECT 02 · RETRIEVAL-AUGMENTED GENERATION↗

DocuTrace — Multi-PDF RAG Assistant

An end-to-end RAG assistant over multiple PDFs, designed to keep retrieved evidence traceable to the original document and page.

  • Page-level text extraction, recursive chunking, 384-dimensional MiniLM embeddings and a persistent ChromaDB vector store.
  • Hybrid retrieval combining dense search with BM25 through reciprocal rank fusion.
  • Evidence display with document/page references and retrieval evaluation using Precision@K, Recall@K and MRR on sample DataOps documents.
  • Automated tests for core retrieval behaviour.
PYTHON · STREAMLIT · PYMUPDF · SENTENCE TRANSFORMERS · CHROMADB · GEMINI
